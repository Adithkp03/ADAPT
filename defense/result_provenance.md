# D5.14 — Defense: Result Provenance

How to answer "where did this number come from?" for any number in the
artifact.

## Evidence taxonomy (D5.2 audit)

| Badge | Meaning | Where |
|---|---|---|
| LIVE | computed at request time by the real engine | `/api/episode` etc. |
| PRECOMPUTED | vetted research run, re-stamped w/ provenance | `/api/precomputed`, `/api/figure` |
| SYNTHETIC | procedurally generated task data | all live payloads |
| PUBLISHED / OFFICIAL | cited from a paper/official repo (scope-guarded) | BDH, BDH-CQ numbers |
| ILLUSTRATIVE | educational rendering, not a simulation | BDH stepper/synapse cards |

## Provenance envelope (every live payload)

```json
{ "seed": 7, "split": "test",
  "task_generator_version": "taskgen-v2",
  "model_version": "adapt-v2",
  "git_commit": "<8-hex>",
  "config_hash": "<hash>",
  "result_schema_version": 1 }
```

## Every result file

`research/experiments/*/results.json` contains `config` (family,
strategies, kwargs, seeds), `summary` (accuracy, Wilson 95% CI, deltas,
n), `diffs` (paired stats), `provenance` (commit/config hash/versions),
`evidence_type`. SHA-256 pins: `repro/expected_outputs/manifest.csv`.

## Every figure

`results/final/*.png` regenerated by `make_figures.py`; hashes in
`results/final_manifest.csv` (D5.9 freeze).

## BDH / BDH-CQ numbers — the honesty rule (D5.2)

- Structure = PUBLISHED, our probes = TOY_EXPERIMENT; **two labels never
  merge** (`research/bdh/reproductions/README.md`).
- BDH-CQ 150M / 29.5%: PUBLISHED + configuration-specific scope guard;
  R2 by us did not reproduce it — reported, not hidden.
- BDH 97.4% Sudoku: PUBLISHED + repo pin; R1 by us did not reproduce —
  reported, not hidden.

## Live-vs-precomputed answer for a judge

"Is this graph live?" → check the badge + provenance envelope. If it
came from `/api/sweep` or `/api/episode`, a fresh run re-derives it;
if it came from `/api/precomputed`, it is the pinned research run with
its git_commit. Nothing is animated to a claim — `web/app.js` renders
what the API returns.
