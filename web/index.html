BDH — brain-inspired Post-Transformer

  • Scale-free graph of locally interacting neuron particles (few hubs, many low-degree nodes).
  • Working memory in synaptic state σ via Hebbian updates — transient, not trained weights.
  • Sparse positive activations; GPU-friendly formulation. Sources: BDH paper (arXiv 2025), Pathway “Equations of Reasoning”, public repo pathwaycom/bdh.

Educational implementation (not official BDH code) of the published update form σ ← σ + η·x·yT. Move η — the update magnitude below is computed live from your value:

BDH-CQ — memory + latent reasoning, no verbal chain-of-thought

Per the BDH-CQ paper (arXiv 2026): demonstrations update recurrent memory, then the query is solved by iterative latent computation — parameters static during inference. Reported configuration-specific result: 150M, 29.5% pass@2 on ARC-AGI-1 at computed $0.0007/task (do not generalize beyond that configuration).
