# D5.12 — Licenses

Project decision: **MIT** for the ADAPT-authored code and prose (declared
in `LICENSE`; the maintainer applies it at packaging time). What follows
is the full inventory of what is ours vs. what is referenced but not
shipped.

## Source code (ours)

All `.py`, `.html`, `.css`, `.js`, configuration, test, and script
files were written for this project (Phases 1–5). See
`provenance/code.csv`.

## Data (ours, generated)

All task data is procedurally generated in-repo (seeded RNG, no
external corpus) — unencumbered. Learner-session data is consent-scoped
and not published. See `provenance/data.csv`.

## Models / checkpoints

- Controlled strategies and learned trio checkpoints: our training /
  hand-specified dynamics — our license applies.
- BDH / BDH-CQ **weights are NOT distributed here**; they are referenced
  by paper/repo citation only (their analysis remains with their
  authors). See `provenance/models.csv`.

## Graphics

Figures fig1–fig8 are generated by our own `make_figures.py` from our
own results — ours. No paper figures are reused; a paper concept that
is shown is redrawn with attribution. The BDH stepper/synapse cards in
the UI are our educational renderings of a published structure,
explicitly labelled ILLUSTRATIVE. See `provenance/assets.csv`.

## Fonts

No webfonts — system font stack only (`provenance/fonts.csv`). Zero font
licensing exposure.

## Paper figures (audit)

Policy (D5.9 / §59): if a paper figure cannot be legally reused, redraw
it ourselves based on the concept, with attribution — which is what we
do. We ship none of the papers' figures, icons, or text.

## References, not redistribution

Papers and official repositories are cited precisely where claims use
them (`docs/sources.md`); citing is not redistributing.
